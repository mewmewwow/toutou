# 1. 产品概述

## 1.1 产品定位

词善佳是一款基于FSRS间隔重复算法的智能英语单词学习网页应用。产品采用科学的记忆理论，通过多维度学习方式（形、音、义的组合训练），帮助学生高效记忆英语单词和例句。

## 1.2 目标用户

主要面向各阶段学生群体：大学生（四六级）、研究生（考研）、中学生（中高考）、出国留学备考者（雅思、托福、GRE）及其他英语学习者。

## 1.3 产品形态

网页应用（Web App），优先保证桌面端体验。移动端网页适配为可选优化项。

## 1.4 设计原则

*「如无必要，勿增实体」* —— 产品设计追求简洁高效，专注核心学习体验。

## 1.5 MVP范围

本文档MVP版本包含7个学习模块：

**单词模块（3个）：**智能认词、智能听写、智能默写

**例句模块（3个）：**例句听组、例句翻译、例句听写

**过渡模块（1个）：**智能用词

**后期扩展模块：**智能听词、智能跟读、智能说词、例句听力、例句口语、例句默写

# 3. 核心学习模块

## 3.1 学习维度设计理念

传统背单词效率低下的原因：大脑带宽有限，一次性展示全部信息会导致学习混沌。词善佳采用「各个击破」策略，将单词学习拆分为形（拼写）、音（发音）、义（释义）三个核心元素的组合训练。

## 3.2 模块类型定义（module_type）

| **ID** | **模块名称** | **方向**   | **MVP状态** |
| ------ | ------------ | ---------- | ----------- |
| 1      | 智能认词     | 形→义      | 必做        |
| 2      | 智能听写     | 音→形      | 必做        |
| 3      | 智能默写     | 义→形      | 必做        |
| 4      | 智能听词     | 音→义      | 后期        |
| 5      | 智能跟读     | 形→音      | 后期        |
| 6      | 智能说词     | 义→音      | 后期        |
| 7      | 智能用词     | 例句填空   | 必做        |
| 8      | 例句听组     | 听音排序   | 必做        |
| 9      | 例句翻译     | 中译英排序 | 必做        |
| 10     | 例句听写     | 听音拼写   | 必做        |
| 11     | 例句听力     | 听音选义   | 后期        |
| 12     | 例句口语     | 跟读例句   | 后期        |
| 13     | 例句默写     | 看中写英   | 后期        |

## 3.3 内容层级结构

**单词书 > Unit（约70词） > 单词**

**隔离原则：**

• 不同单词书之间：学习进度和复习追踪相互独立

• 同一单词不同模块之间：复习追踪互不干扰（如认词模块毕业不影响听写模块）

## 3.4 快捷键设计

| **快捷键** | **功能**             |
| ---------- | -------------------- |
| Ctrl       | 重播单词发音         |
| Shift      | 播放例句发音         |
| Enter      | 提交答案             |
| 1/2/3/4    | 选择选项（测试时）   |
| Tab        | 跳转下一题（测试时） |

## 3.5 有效时间规则

适用于所有模块。每道题用户最高作答时间60秒：

• 60秒内作答完成：计入实际用时

• 超过60秒：按60秒计算

用途：计算学习金币、统计每日学习状态

## 3.6 发音资源

使用有道词典API真人发音：

https://dict.youdao.com/dictvoice?audio={word}&type={1|2}

type=1 英音，type=2 美音。用户可在设置中切换，默认美音。

 

# 4. 单词学习模块详细设计

## 4.1 智能认词模块

**模块目的：**通过两次确认机制帮助用户熟悉单词，为后续听写、默写模块做准备。

### 4.1.1 学习流程

1. 系统显示单词（如"cancel"），同时播放发音
2. 从播放发音开始计时5秒
3. 用户选择 😊（认识）或 😭（不认识）

**情况一：5秒内点击😊**

→ 显示单词和汉义，再次播放发音

→ 用户点击 ✅（确认认识）：标记为「熟词」，在认词模块直接毕业，不再安排复习

→ 用户点击 ❌（其实不认识）：评分0分，进入生词学习流程

**情况二：5秒内点击😭**

→ 评分0分，进入生词学习流程

**情况三：超过5秒后操作**

→ 界面显示「已超时」

→ 5-10秒点😊+✅：评分3分，跟读1遍

→ 10-15秒点😊+✅：评分2分，跟读1遍

→ 15-20秒点😊+✅：评分1分，跟读1遍

→ 超过20秒或点❌：评分0分，跟读2遍

### 4.1.2 生词学习流程

1. 显示单词、汉义、主例句
2. 播放英文发音，顺序高亮单词和汉义
3. 引导用户跟读（强制完成规定次数）
4. 跟读判定：用户必须点击「跟读」按钮完成播放，系统不检测语音
5. 完成跟读后显示「下一个」按钮

### 4.1.3 FSRS评分规则

| **用户操作** | **时间** | **FSRS评分** | **后续处理**   |
| ------------ | -------- | ------------ | -------------- |
| 5秒内😊+✅     | -        | 毕业         | 不参与FSRS复习 |
| 5秒内😊+❌     | -        | 0分          | 跟读2遍        |
| 超时😊+✅      | 5-10秒   | 3分          | 跟读1遍        |
| 超时😊+✅      | 10-15秒  | 2分          | 跟读1遍        |
| 超时😊+✅      | 15-20秒  | 1分          | 跟读1遍        |
| 😭或>20秒     | 任意     | 0分          | 跟读2遍        |

### 4.1.4 词义强化

**触发时机：**每学完10个单词自动触发

**强化对象：**刚学的10个词（不区分生词/熟词，全部参与）

**流程：**

1. 显示汉语意思
2. 自动播放英文发音（用户可按Ctrl重播）
3. 用户默写单词（无倒计时，有效时间上限60秒）
4. 正确：进入下一词
5. 错误：进入抄写流程，抄写正确后重新默写直至正确

**重要：**词义强化结果不影响FSRS评分和复习安排，目的是确保用户能拼写认识的单词。

 

## 4.2 智能听写模块

**模块目的：**建立「发音」与「拼写」的关联。

### 4.2.1 学习流程

1. 系统自动播放单词发音
2. 用户在输入框中拼写单词
3. 按Ctrl可重复播放发音
4. 按Enter提交答案
5. 系统批改并显示结果

### 4.2.2 倒计时规则

**倒计时 = 单词字母数 × 2 秒**

例如：「discount」8个字母，倒计时16秒

### 4.2.3 FSRS评分规则

**首次学习：**

• 规定时间内正确：该词在听写模块「直接毕业」，不再安排复习

• 错误或超时：评分0分，进入生词学习流程，安排FSRS复习

**复习时：**

• 正确：给FSRS最高分，继续按FSRS安排下次复习

• 错误：给0分

### 4.2.4 拼写错误处理（挖空抄写）

1. 显示正确答案，标注错误部分（红色删除线 + 绿色正确字母）
2. 将错误单词挖空，要求用户抄写
3. 抄写时逐字母比对：正确则显示，错误则删除并高亮正确字母
4. 抄写完成后，重新默写
5. 只有完全默写正确才能进入下一词

## 4.3 智能默写模块

**模块目的：**建立「汉语释义」与「单词拼写」的关联。

流程与听写模块类似，区别：显示汉语意思而非播放发音。

倒计时、评分规则、错误处理均与听写模块相同。

### 默写与抄写的区别

| **对比项** | **默写**          | **抄写**               |
| ---------- | ----------------- | ---------------------- |
| 触发时机   | 看汉义写单词      | 默写错误后纠错         |
| 提交方式   | 按Enter提交       | 逐字母实时比对         |
| 批改时机   | 按Enter后统一批改 | 每输入一字母即时批改   |
| 错误处理   | 显示完整批改结果  | 错误字母立即删除并提示 |

 

# 5. 例句学习模块详细设计

## 5.1 例句数据结构

• 每个单词配1-2个例句

• 默认只显示主例句（第一个），用户可点击按钮展开查看其他例句

• 例句学习只针对主例句进行，其他例句仅供参考

## 5.2 例句听组模块

**学习形式：**听英文句子发音，将打乱的单词拖拽排列成正确语序。

1. 系统播放英文句子发音
2. 发音完毕后显示打乱顺序的单词
3. 开始倒计时
4. 用户点击/拖拽单词排列成正确顺序
5. 回答正确播放提示音，点击箭头进入下一题

## 5.3 例句翻译模块

**学习形式：**看中文句子，将打乱的英文单词排列成正确翻译。

• 显示汉语句子意思（无发音）

• 显示打乱顺序的英文单词

• 用户排列成正确的英文句子

## 5.4 例句听写模块

**学习形式：**听英文句子发音，逐词输入完整句子。

• 系统播放英文句子发音

• 用户在输入框中输入完整句子

• 按Enter提交，系统批改

• 错误单词进入挖空抄写模式

**倒计时：**句子字符数 × 2 秒

## 5.5 智能用词模块（过渡模块）

**学习形式：**听例句发音，填写挖空的单词。

• 显示例句，重点单词挖空

• 播放完整例句发音

• 用户在空格处填写听到的单词

• 按Enter提交，系统批改

**定位：**作为单词学习和例句学习之间的过渡模块。

**触发效果：**不能学习新内容，必须完成复习清掉到期数据

# 8. FSRS间隔重复算法

## 8.1 算法选型

采用FSRS-v6算法（21个参数），使用官方默认参数。

参考：https://github.com/open-spaced-repetition/fsrs4anki/wiki/The-Algorithm

## 8.2 核心参数

• Difficulty（难度）：单词本身的记忆难度

• Stability（稳定性）：记忆的「半衰期」

• Retrievability（可提取度）：当前时刻能回忆起的概率

• 目标记忆保持率：90%

• 复习时间精度：精确到秒

## 8.3 记忆引擎档位（面向用户）

| **档位** | **Stability范围** | **记忆状态**   |
| -------- | ----------------- | -------------- |
| 档位1    | < 1天             | 刚学，很不稳定 |
| 档位2    | 1-7天             | 初步建立       |
| 档位3    | 7-30天            | 逐渐巩固       |
| 档位4    | 30-90天           | 比较牢固       |
| 档位5    | > 90天            | 长期记忆       |

## 8.4 记忆强度显示

使用Retrievability参数作为「记忆强度」百分比显示。

计算公式：R = (1 + t/(9*S))^(-1)

其中 t = 距离上次复习的时间（天），S = Stability

 

# 9. 激励系统

# 10. 数据结构设计

## 10.1 词库数据格式

词库来源：https://github.com/kajweb/dict

格式：JSON

MVP使用字段：

| **字段路径**                            | **说明**             |
| --------------------------------------- | -------------------- |
| headWord                                | 单词                 |
| content.word.content.usphone            | 美音音标             |
| content.word.content.ukphone            | 英音音标             |
| content.word.content.usspeech           | 美音发音参数         |
| content.word.content.ukspeech           | 英音发音参数         |
| content.word.content.trans              | 释义数组（含词性）   |
| content.word.content.sentence.sentences | 例句数组（含中英文） |

暂不使用：phrase（短语）、syno（近义词）、relWord（同根词）、exam（真题）

## 10.2 核心数据表

### users表

id, email, phone, password_hash, username, avatar, birthday, total_coins, total_credits, level, member_type, member_expire_at, created_at

### books表

id, name, description, total_words, total_units, is_free（高中及以下免费）

### words表

id, book_id, unit_id, word, phonetic_us, phonetic_uk, audio_us, audio_uk, definition, pos

### sentences表

id, word_id, content_en, content_cn, is_primary（是否主例句）

### cards表（FSRS学习卡片）

id, user_id, word_id, module_type, stability, difficulty, due_at（精确到秒）, status, last_review_at, review_count, error_count

### revlog表（复习日志）

id, card_id, user_id, timestamp, rating, response_time_ms, interval_before, interval_after, review_type

### user_devices表（设备管理）

id, user_id, device_fingerprint, device_name, last_active_at, created_at

## 10.3 API设计要点

• GET /study/next：批量返回10个词

• POST /study/review：每学完1个词立即提交

• 网络断开：本地缓存，恢复后自动同步

• 提交失败：自动重试3次，仍失败则本地缓存
