 

**词善佳**

智能英语单词学习系统

**产品需求文档（****PRD）**

版本：V1.0 MVP

日期：2026年1月

 

# 1. 产品概述

## 1.1 产品定位

词善佳是一款基于FSRS间隔重复算法的智能英语单词学习网页应用。产品采用科学的记忆理论，通过多维度学习方式（形、音、义的组合训练），帮助学生高效记忆英语单词和例句。

## 1.2 目标用户

主要面向各阶段学生群体：大学生（四六级）、研究生（考研）、中学生（中高考）及其他英语学习者。

## 1.3 产品形态

网页应用（Web App），优先保证桌面端体验。移动端网页适配为可选优化项，暂不考虑原生App。

## 1.4 设计原则

*「如无必要，勿增实体」* —— 产品设计追求简洁高效，专注核心学习体验。

## 1.5 MVP范围

本文档MVP版本包含：用户系统、单词学习三大必学模块（认词/听写/默写）、例句学习三大必学模块（听组/翻译/听写）、FSRS间隔重复算法、测试闯关系统、激励系统。

 

# 2. 核心功能模块

## 2.1 学习维度设计理念

传统背单词效率低下的原因：大脑带宽有限，一次性展示全部信息会导致学习混沌。词善佳采用「各个击破」策略，将单词学习拆分为多个独立维度进行精准训练。

## 2.2 六大学习维度

单词学习涉及形（拼写）、音（发音）、义（释义）三元素，两两组合形成六个维度：

| **维度** | **方向** | **学习形式**   | **MVP状态**  |
| -------- | -------- | -------------- | ------------ |
| 形→义    | 认词     | 看单词选汉义   | 必学         |
| 义→形    | 默写     | 看汉义写单词   | 必学         |
| 音→形    | 听写     | 听发音写单词   | 必学         |
| 音→义    | 听词     | 听发音选汉义   | 选学（后期） |
| 形→音    | 跟读     | 看单词跟读发音 | 选学（后期） |
| 义→音    | 说词     | 看汉义说单词   | 选学（后期） |

## 2.3 内容层级结构

**单词书 > Unit（约70词） > 单词**

每本单词书的学习进度相互独立，复习追踪只在当前单词书的学习界面内生效。

支持：邮箱注册、手机号注册、第三方登录（微信/Google）。注册流程简洁，生日等信息在个人资料中选填。

# 4. 单词学习模块

## 4.1 智能认词模块（形→义）

### 4.1.1 学习流程

1. 显示单词+播放发音 → 2. 开始5秒倒计时 → 3. 用户选择😊（认识）或😭（不认识）

**情况一：5秒内点😊**

显示汉义，用户点✅确认认识=熟词毕业；点❌其实不认识=0分进入生词学习

**情况二：5秒内点😭**

0分，进入生词学习流程

**情况三：超时后操作**

5-10秒=3分，10-15秒=2分，15-20秒=1分，>20秒=0分

### 4.1.2 生词学习流程

显示单词+汉义+例句 → 播放发音并高亮 → 强制跟读两遍 → 完成后进入下一词

### 4.1.3 词义强化

**触发时机：**每学完10个词自动触发

**强化对象：**刚学的10个词（不区分生词/熟词）

**流程：**显示汉义→播放发音→用户默写（无倒计时，有效时间上限60秒）→正确则下一词/错误则抄写

**重要：**词义强化结果不影响FSRS评分；抄写错误不算生词

### 4.1.4 FSRS评分规则

| **用户操作** | **时间范围** | **FSRS评分** | **后续处理**   |
| ------------ | ------------ | ------------ | -------------- |
| 5秒内😊+✅     | -            | 毕业         | 不参与FSRS复习 |
| 5秒内😊+❌     | -            | 0分          | 跟读2遍        |
| 超时😊+✅      | 5-10秒       | 3分          | 跟读1遍        |
| 超时😊+✅      | 10-15秒      | 2分          | 跟读1遍        |
| 超时😊+✅      | 15-20秒      | 1分          | 跟读1遍        |
| 😭/超过20秒   | 任意         | 0分          | 跟读2遍        |

## 4.2 智能听写模块（音→形）

**流程：**播放发音→用户拼写→按回车提交→系统批改

**倒计时：**单词字母数 × 2 秒

**评分：**规定时间内正确=毕业；错误/超时=0分

**错误处理：**进入挖空抄写模式，逐字母比对，抄写正确后重新默写直至完全正确

## 4.3 智能默写模块（义→形）

**流程：**显示汉义→用户默写→按回车提交→系统批改

倒计时和评分规则与听写模块相同

### 默写与抄写的区别

| **对比项** | **默写**             | **抄写**               |
| ---------- | -------------------- | ---------------------- |
| 触发时机   | 看汉义写单词         | 默写错误后的纠错环节   |
| 提交方式   | 输入完成后按回车提交 | 逐字母实时比对         |
| 批改时机   | 按回车后统一批改     | 每输入一个字母即时批改 |
| 错误处理   | 显示完整批改结果     | 错误字母立即删除并提示 |

 

# 5. 例句学习模块

例句也参与FSRS间隔重复算法。MVP实现三个必学模块。

## 5.1 例句听组模块

播放英文句子→显示打乱单词→用户排列成正确语序

## 5.2 例句翻译模块

显示中文句子→显示打乱英文单词→用户排列成正确翻译

## 5.3 例句听写模块

播放英文句子→用户输入完整句子→按回车批改→错误单词进入挖空抄写

**倒计时：**句子字符数 × 2 秒

## 5.4 智能用词模块

显示挖空例句→播放发音→用户填写听到的单词→回车批改（过渡模块）

 

# 6. 测试与闯关系统

## 6.1 测试前置条件

**强制复习：**每次测试前检查到期生词，有则强制完成完整学习流程后方可测试

## 6.2 认词模块测试

**测试范围：**100%覆盖Unit所有单词

**普通模式：**试卷模式，分英译汉+汉译英两组，总时间限制，通过≥90分

**极速挑战：**卡片逐题，总时间3分钟，含「以上都不对」选项

**终极挑战：**单题5秒限制，超时自动跳转

## 6.3 听写/默写模块测试

**测试范围：**仅测试学习中产生的生词（无生词则随机抽10个）

**普通模式：**双列布局，光标停留自动播放/显示

**极速挑战：**总时间5分钟

**终极挑战：**单题10秒限制

## 6.4 进度状态图标

| **图标** | **状态** | **含义**         |
| -------- | -------- | ---------------- |
| ○        | 未学     | 尚未开始学习     |
| ●        | 正在学   | 学习进行中       |
| ⊙        | 未测     | 学习完成，未测试 |
| ●        | 通过     | 普通模式通过     |
| ⊗        | 未通过   | 最近测试未通过   |
| ◎        | 极速挑战 | 极速挑战通过     |
| ◉        | 终极挑战 | 终极挑战通过     |

**星星获取：**普通/极速/终极各通关一次获一颗星，每模块最多3星

 

# 7. 间隔重复算法（FSRS）

## 7.1 算法选型

采用FSRS（Free Spaced Repetition Scheduler）算法，使用DSR模型：Difficulty（难度）、Stability（稳定性）、Retrievability（可提取度）

## 7.2 记忆引擎档位

面向用户展示，基于Stability参数划分：

| **档位** | **Stability范围** | **记忆状态**   |
| -------- | ----------------- | -------------- |
| 档位1    | < 1天             | 刚学，很不稳定 |
| 档位2    | 1-7天             | 初步建立       |
| 档位3    | 7-30天            | 逐渐巩固       |
| 档位4    | 30-90天           | 比较牢固       |
| 档位5    | > 90天            | 长期记忆       |

## 7.3 复习优先级

1. 词义强化中不插入老词复习 2. 老词到期复习 > 新词学习 3. 测试前强制完成到期生词学习 4. 词义强化后立即检查到期复习

 

# 8. 激励系统

## 8.1 金币系统

**学习类金币（每日上限500）：**每分钟有效时长1金币；认词闯关10金币；听写/默写闯关20金币；例句闯关30金币

**奖励类金币（无上限）：**首登5金币；累计登录奖励；抢红包10-30金币；生日100金币；PK胜利1-50金币

## 8.2 每周奖牌

| **奖牌** | **周金币** |
| -------- | ---------- |
| 勤勉顽石 | ≥99        |
| 英勇黑铁 | ≥199       |
| 不屈青铜 | ≥299       |
| 无畏白银 | ≥599       |
| 荣耀黄金 | ≥999       |
| 华贵铂金 | ≥1499      |
| 璀璨钻石 | ≥1999      |

## 8.3 课程证书

每课程最多11个证书：智能认词/听词/听写/默写/用词 + 例句听组/听力/翻译/听写/默写 + 全能证书（10模块均≥95分）

## 8.4 等级系统

基于总学分：1级0-99，2级100-299，3级300-599...10级3500-3999，11-20级每1000分升一级，21级+每2000分升一级

## 8.5 PK系统

**模式：**异步挑战。用户A发起（选题+押注1-50金币）→A先答→通知B→B24小时内应战→比较成绩定胜负

**限制：**每人每天4次机会
