# 1. 产品概述

## 1.1 产品定位

词善佳是一款基于 FSRS 间隔重复算法的智能英语单词学习网页应用。产品采用科学的记忆理论，通过多维度学习方式（形、音、义的组合训练），帮助学生高效记忆英语单词和例句。

## 1.2 目标用户

主要面向各阶段学生群体：大学生（四六级）、研究生（考研）、中学生（中高考）、出国留学备考者（雅思、托福、GRE）及其他英语学习者。

## 1.3 产品形态

网页应用（Web App），优先保证桌面端体验。移动端网页适配为可选优化项。

## 1.4 设计原则

_「如无必要，勿增实体」_ —— 产品设计追求简洁高效，专注核心学习体验。

## 1.5 MVP 范围

本文档 MVP 版本包含 7 个学习模块：

**单词模块（3 个）：**智能认词、智能听写、智能默写

**例句模块（3 个）：**例句听组、例句翻译、例句听写

**过渡模块（1 个）：**智能用词

**后期扩展模块：**智能听词、智能跟读、智能说词、例句听力、例句口语、例句默写

# 2. 用户系统与会员体系

## 2.1 用户类型与权限

| **用户类型**         | **权限范围**        | **限制**         |
| -------------------- | ------------------- | ---------------- |
| 游客（未注册）       | 任意词书第一单元    | 无法保存学习统计 |
| 免费用户（已注册）   | 所选词书全部单元    | 14 天试用期      |
| 免费用户（试用到期） | 所选词书第一单元    | 等同游客权限     |
| 付费会员             | 全部词书 + 全部功能 | 无限制           |
| 特殊：高中及以下词书 | 完全免费            | 所有用户可用     |

## 2.2 注册与登录

支持四种方式：邮箱注册、手机号注册（腾讯云短信）、微信登录、Google 登录。

注册流程简洁，生日等信息在个人资料中选填。

## 2.3 开放式体验设计

产品采用「先体验后注册」策略：

1. 用户无需注册即可选择词书，学习第一单元
2. 学习完成后查看统计结果时引导注册
3. 注册提示：「注册后可解锁更多单元，并获得 14 天免费体验」
4. **无缝数据迁移**：
   - 游客访问时，系统生成唯一 `device_fingerprint` 存入本地存储（localStorage）。
   - 游客的所有学习记录 (`revlog`) 和卡片状态 (`cards`) 均关联此指纹 ID。
   - 用户注册/登录成功时，前端自动提交 `device_fingerprint`。
   - 后端检测到该指纹下有未归属数据，触发 **Data Merging** 流程，将游客数据的所有权转移至新注册的 `user_id`，实现无感继承。

## 2.4 全场试用期逻辑

- **全局试用**：新用户注册后，即刻获得 **全场 14 天 VIP 权限**（不通过词书单独计算），可体验所有词书和所有功能。
- **倒计时提醒**：顶部导航栏显示「VIP 试用剩余 X 天」。
- **过期降级**：14 天结束后如未付费，账号状态自动降级为「免费用户」，所有非第一单元的学习进度被锁定（数据保留但不展示），仅保留第一单元访问权。

## 2.5 付费价值点

• 解锁全部词书（四六级、考研、雅思、托福、GRE...）

• FSRS 记忆算法个性化参数优化

• 完整学习数据追踪与分析报告

• 学习进度云端同步，多设备无缝切换

• 智能复习提醒推送

• 记忆曲线可视化

• 每日金币上限提升、PK 次数翻倍

• 学习证书导出

## 2.6 设备限制（防共享）

• 同时在线设备数：最多 3 台

• 新设备登录需邮箱/短信验证码

• 每月最多添加 5 台新设备

• 新设备登录时，最早登录的设备被踢下线并收到通知

# 3. 核心学习模块

## 3.1 学习维度设计理念

传统背单词效率低下的原因：大脑带宽有限，一次性展示全部信息会导致学习混沌。词善佳采用「各个击破」策略，将单词学习拆分为形（拼写）、音（发音）、义（释义）三个核心元素的组合训练。

## 3.2 模块类型定义（module_type）

| **ID** | **模块名称** | **方向**   | **MVP 状态** |
| ------ | ------------ | ---------- | ------------ |
| 1      | 智能认词     | 形 → 义    | 必做         |
| 2      | 智能听写     | 音 → 形    | 必做         |
| 3      | 智能默写     | 义 → 形    | 必做         |
| 4      | 智能听词     | 音 → 义    | 后期         |
| 5      | 智能跟读     | 形 → 音    | 后期         |
| 6      | 智能说词     | 义 → 音    | 后期         |
| 7      | 智能用词     | 例句填空   | 必做         |
| 8      | 例句听组     | 听音排序   | 必做         |
| 9      | 例句翻译     | 中译英排序 | 必做         |
| 10     | 例句听写     | 听音拼写   | 必做         |
| 11     | 例句听力     | 听音选义   | 后期         |
| 12     | 例句口语     | 跟读例句   | 后期         |
| 13     | 例句默写     | 看中写英   | 后期         |

## 3.3 内容层级结构

**单词书 > Unit（约 70 词） > 单词**

**隔离原则：**

• 不同单词书之间：学习进度和复习追踪相互独立

• 同一单词不同模块之间：复习追踪互不干扰（如认词模块毕业不影响听写模块）

## 3.4 快捷键设计

| **快捷键** | **功能**             |
| ---------- | -------------------- |
| Ctrl       | 重播单词发音         |
| Shift      | 播放例句发音         |
| Enter      | 提交答案             |
| 1/2/3/4    | 选择选项（测试时）   |
| Tab        | 跳转下一题（测试时） |

## 3.5 有效时间规则

适用于所有模块。每道题用户最高作答时间 60 秒：

• 60 秒内作答完成：计入实际用时

• 超过 60 秒：按 60 秒计算

用途：计算学习金币、统计每日学习状态

## 3.6 发音资源

使用有道词典 API 真人发音：

https://dict.youdao.com/dictvoice?audio={word}&type={1|2}

type=1 英音，type=2 美音。用户可在设置中切换，默认美音。

# 4. 单词学习模块详细设计

## 4.1 智能认词模块

**模块目的：**通过两次确认机制帮助用户熟悉单词，为后续听写、默写模块做准备。

### 4.1.1 学习流程

1. 系统显示单词（如"cancel"），同时播放发音
2. 从播放发音开始计时 5 秒
3. 用户选择 😊（认识）或 😭（不认识）

**情况一：5 秒内点击 😊**

→ 显示单词和汉义，再次播放发音

→ 用户点击 ✅（确认认识）：标记为「熟词」，在认词模块直接毕业，不再安排复习

→ 用户点击 ❌（其实不认识）：评分 0 分，进入生词学习流程

**情况二：5 秒内点击 😭**

→ 评分 0 分，进入生词学习流程

**情况三：超过 5 秒后操作**

→ 界面显示「已超时」

→ 5-10 秒点 😊+✅：评分 3 分，跟读 1 遍

→ 10-15 秒点 😊+✅：评分 2 分，跟读 1 遍

→ 15-20 秒点 😊+✅：评分 1 分，跟读 1 遍

→ 超过 20 秒或点 ❌：评分 0 分，跟读 2 遍

### 4.1.2 生词学习流程

1. 显示单词、汉义、主例句
2. 播放英文发音，顺序高亮单词和汉义
3. 引导用户跟读（强制完成规定次数）
4. 跟读判定：用户必须点击「跟读」按钮完成播放，系统不检测语音
5. 完成跟读后显示「下一个」按钮

### 4.1.3 FSRS 评分规则

| **用户操作** | **时间** | **FSRS 评分** | **后续处理**             |
| ------------ | -------- | ------------- | ------------------------ |
| 5 秒内 😊+✅ | -        | 毕业          | 不参与 FSRS 复习（归档） |
| 5 秒内 😊+❌ | -        | 0 分          | 跟读 2 遍                |
| 超时 😊+✅   | 5-10 秒  | 3 分          | 跟读 1 遍                |
| 超时 😊+✅   | 10-15 秒 | 2 分          | 跟读 1 遍                |
| 超时 😊+✅   | 15-20 秒 | 1 分          | 跟读 1 遍                |
| 😭 或>20 秒  | 任意     | 0 分          | 跟读 2 遍                |

### 4.1.4 词义强化

**触发时机：**每学完 10 个单词自动触发

**强化对象：**刚学的 10 个词（不区分生词/熟词，全部参与）

**流程：**

1. 显示汉语意思
2. 自动播放英文发音（用户可按 Ctrl 重播）
3. 用户默写单词（无倒计时，有效时间上限 60 秒）
4. 正确：进入下一词
5. 错误：进入抄写流程，抄写正确后重新默写直至正确

**重要：**词义强化结果不影响 FSRS 评分和复习安排，目的是确保用户能拼写认识的单词。

## 4.2 智能听写模块

**模块目的：**建立「发音」与「拼写」的关联。

### 4.2.1 学习流程

1. 系统自动播放单词发音
2. 用户在输入框中拼写单词
3. 按 Ctrl 可重复播放发音
4. 按 Enter 提交答案
5. 系统批改并显示结果

### 4.2.2 倒计时规则

**倒计时 = 单词字母数 × 2 秒**

例如：「discount」8 个字母，倒计时 16 秒

### 4.2.3 FSRS 评分规则

**首次学习：**

• 规定时间内正确：该词在听写模块「直接毕业」，标记为「已掌握」，不再安排 FSRS 复习。

• 错误或超时：评分 0 分，进入生词学习流程，安排 FSRS 复习

**关于「毕业」的说明：**
用户首遍就能掌握的词被视为「熟词」，系统将其从复习队列中**永久剔除**，旨在让用户把精力集中在真正的生词上。

**复习时：**

• 正确：给 FSRS 最高分，继续按 FSRS 安排下次复习

• 错误：给 0 分

### 4.2.4 拼写错误处理（挖空抄写）

1. 显示正确答案，标注错误部分（红色删除线 + 绿色正确字母）
2. 将错误单词挖空，要求用户抄写
3. 抄写时逐字母比对：正确则显示，错误则删除并高亮正确字母
4. 抄写完成后，重新默写
5. 只有完全默写正确才能进入下一词

## 4.3 智能默写模块

**模块目的：**建立「汉语释义」与「单词拼写」的关联。

流程与听写模块类似，区别：显示汉语意思而非播放发音。

倒计时、评分规则、错误处理均与听写模块相同。

### 默写与抄写的区别

| **对比项** | **默写**            | **抄写**               |
| ---------- | ------------------- | ---------------------- |
| 触发时机   | 看汉义写单词        | 默写错误后纠错         |
| 提交方式   | 按 Enter 提交       | 逐字母实时比对         |
| 批改时机   | 按 Enter 后统一批改 | 每输入一字母即时批改   |
| 错误处理   | 显示完整批改结果    | 错误字母立即删除并提示 |

# 5. 例句学习模块详细设计

## 5.1 例句数据结构

例句取自上面学习的单词配的主例句:
• 每个单词配 1-2 个例句

• 默认只显示主例句（第一个），用户可点击按钮展开查看其他例句

• 例句学习只针对主例句进行，其他例句仅供参考

## 5.2 例句听组模块

**学习形式：**听英文句子发音，将打乱的单词拖拽排列成正确语序。

1. 系统播放英文句子发音
2. 发音完毕后显示打乱顺序的单词
3. 开始倒计时
4. 用户点击/拖拽单词排列成正确顺序
5. 回答正确播放提示音，点击箭头进入下一题

## 5.3 例句翻译模块

**学习形式：**看中文句子，将打乱的英文单词排列成正确翻译。

• 显示汉语句子意思（无发音）

• 显示打乱顺序的英文单词

• 用户排列成正确的英文句子

## 5.4 例句听写模块

**学习形式：**听英文句子发音，逐词输入完整句子。

• 系统播放英文句子发音

• 用户在输入框中输入完整句子

• 按 Enter 提交，系统批改

• 错误单词进入挖空抄写模式

**倒计时：**句子字符数 × 2 秒

## 5.5 智能用词模块（过渡模块）

**学习形式：**听例句发音，填写挖空的单词。

• 显示例句，此例句关联的单词挖空

• 播放完整例句发音

• 用户在空格处填写听到的单词

• 按 Enter 提交，系统批改

**定位：**作为单词学习和例句学习之间的过渡模块。

# 6. 记忆追踪与复习系统

## 6.1 记忆追踪页面

显示所有模块产生的生词列表，可按模块筛选查看。

### 6.1.1 显示方式

• 三种视图：词云视图、列表视图、日历视图（右上角切换）

• 默认排序：按到期时间（最紧急在前）

• 字号大小：距离复习日期越近字号越大

• 颜色：默认全黑，hover 时已过期变红、未过期保持黑

### 6.1.2 Hover 浮窗内容

• 单词

• 释义（含词性）

• 学习次数、答错次数（当前模块统计）

• 记忆强度（Retrievability 百分比 + 进度条）

• 复习提示语

### 6.1.3 复习提示语规则

| **状态**     | **提示语**                             |
| ------------ | -------------------------------------- |
| 已过期       | 黄金记忆点已到，为了牢记，请立刻复习。 |
| 0-1 天内到期 | 即将到达最佳复习时间                   |
| 1-7 天内到期 | 记忆状态良好                           |
| 7 天以上     | 记忆牢固                               |

### 6.1.4 导出功能

支持导出 Excel，包含三列：单词拼写、音标、汉语意思

## 6.2 智能复习机制

### 6.2.1 复习入口

• 智能复习总按钮：显示所有模块到期单词总数

• 各模块单独复习按钮：显示该模块待复习数量

### 6.2.2 智能复习流程

点击「智能复习」总按钮后：

1. 按模块顺序复习（认词 → 听写 → 默写 → 例句模块...）
2. 每个模块内按到期时间排序
3. 完成一个模块自动跳转下一个模块

### 6.2.3 强制复习规则

**触发条件：**所有模块中已到期单词之和 > 25 个

**触发效果：**不能学习新内容，必须完成复习清掉到期数据

**时间精度：**FSRS 复习安排精确到秒

## 6.3 复习优先级

1. 词义强化进行中：不插入到期复习
2. 词义强化结束后：立即检查到期复习
3. 日常学习：到期复习 > 新词学习
4. 测试前：强制完成到期生词的完整学习流程

# 7. 测试与闯关系统

## 7.1 测试前置条件

每次测试前检查到期生词，有则强制完成完整学习流程后方可测试。

## 7.2 认词模块测试

**测试范围：**100%覆盖 Unit 所有单词

**测试内容：**先 50 道英译汉，再 50 道汉译英

**干扰项生成：**从同 Unit 其他单词中随机选

### 普通模式

• 试卷模式，双列网格布局

• 总时间限制，单题无限制

• 通过条件：≥90 分
• 总时间 = 题目数量\*3 秒

### 极速挑战

• 卡片逐题模式

• 通过条件：≥90 分
• 总时间 = 题目数量\*3 秒

• 选项含「以上都不对」

### 终极挑战

• 卡片逐题模式

• 通过条件：≥90 分
• 单题 5 秒，超时自动跳转

## 7.3 听写/默写模块测试

**测试范围：**仅测试学习中产生的生词（无生词则随机抽 10 个）

**普通模式：**双列布局，光标停留自动播放/显示

**极速挑战：**总时间 = 题目数量\*10 秒

**终极挑战：**单题 字母数量\*2 秒（从播放发音开始计时）

## 7.4 测试中途退出

下次需要重新开始测试（不保存进度）

## 7.5 进度状态与星星

| **图标** | **状态**     |
| -------- | ------------ |
| ○        | 未学         |
| ●        | 正在学(扇形) |
| ⊙        | 未测         |
| ●        | 通过         |
| ⊗        | 未通过       |
| ◎        | 极速挑战通过 |
| ◉        | 终极挑战通过 |

普通/极速/终极各通关一次获一颗星，每模块最多 3 星。

## 7.6 UI 反馈

• 答对答错：颜色变化（绿/红）+ 音效

• 进度显示：3/10（当前第 3 个，共 10 个）

• 倒计时：数字 + 圆环动画组合

# 8. FSRS 间隔重复算法

## 8.1 算法选型

采用 FSRS-v6 算法（21 个参数），使用官方默认参数。

参考：https://github.com/open-spaced-repetition/fsrs4anki/wiki/The-Algorithm

## 8.2 核心参数

• Difficulty（难度）：单词本身的记忆难度

• Stability（稳定性）：记忆的「半衰期」

• Retrievability（可提取度）：当前时刻能回忆起的概率

• 目标记忆保持率：90%

• 复习时间精度：精确到秒

## 8.3 记忆引擎档位（面向用户）

| **档位** | **Stability 范围** | **记忆状态**   |
| -------- | ------------------ | -------------- |
| 档位 1   | < 1 天             | 刚学，很不稳定 |
| 档位 2   | 1-7 天             | 初步建立       |
| 档位 3   | 7-30 天            | 逐渐巩固       |
| 档位 4   | 30-90 天           | 比较牢固       |
| 档位 5   | > 90 天            | 长期记忆       |

## 8.4 记忆强度显示

使用 Retrievability 参数作为「记忆强度」百分比显示。

计算公式：R = (1 + t/(9\*S))^(-1)

其中 t = 距离上次复习的时间（天），S = Stability
